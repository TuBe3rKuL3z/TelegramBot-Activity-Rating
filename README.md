# 🏆 Telegram-бот учёта активности и рейтинга студентов

Современный асинхронный Telegram-бот на базе **aiogram 3.x** и **SQLAlchemy 2.x (asyncio / SQLite)** для геймификации и автоматизации учета студенческой активности, мероприятий и формирования турнирной таблицы лидеров.

---

## 🛠 Стек технологий

- **Язык**: Python 3.11+
- **Telegram Bot API**: `aiogram 3.x`
- **ORM & База данных**: `SQLAlchemy 2.x` + `aiosqlite` (SQLite c поддержкой связей и каскадного удаления)
- **Конфигурация**: `pydantic-settings` + `python-dotenv`
- **FSM**: Встроенный конечный автомат состояний `aiogram`
- **Архитектура**: Модульная (Handlers, Keyboards, Middlewares, Models, Queries, States)

---

## 🚀 Установка и быстрый старт

### 1. Клонирование репозитория:
```bash
git clone https://github.com/TuBe3rKuL3z/TOP_TelegramBot-Activity-Rating.git
cd TOP_TelegramBot-Activity-Rating
```

### 2. Установка зависимостей:
```bash
pip install -r requirements.txt
```

### 3. Настройка `.env`:
Создайте в корне проекта файл `.env`:
```env
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_IDS=123456789
DATABASE_URL=sqlite+aiosqlite:///activity_rating.db
POINTS_PARTICIPANT=5
POINTS_HELPER=10
POINTS_ORGANIZER=20
```

### 4. Запуск бота:
```bash
python run.py
# или
python -m bot.main
```

База данных и все необходимые таблицы создадутся автоматически при первом запуске!

## 🎯 Возможности бота

### 👨‍🎓 Для студентов:
1. **Онбординг при `/start`**: быстрая регистрация с указанием ФИО и группы.
2. **🎯 Отметить участие**:
   - Выбор активного мероприятия из списка.
   - Выбор роли (Участник `+5`, Помощник `+10`, Организатор `+20`).
   - Защита от повторной подачи заявки на одно и то же мероприятие.
   - Моментальное уведомление администраторов в Telegram о новой заявке.
3. **📊 Мой рейтинг**:
   - Текущий баланс баллов.
   - Точное место в общем рейтинге (например, `#3 из 45`).
   - Баллы, набранные за текущий календарный месяц.
   - История последних 4 начислений.
4. **🏆 Топ студентов**:
   - Топ-10 лучших студентов с медалями (🥇, 🥈, 🥉).
   - Отображение персональной позиции пользователя, если он не входит в топ-10.
5. **📋 Правила начисления**: регламент и условия начисления баллов.

### 👑 Для администраторов:
1. **📥 Заявки на подтверждение**:
   - Карточки заявок в режиме ожидания (`pending`) с постраничной навигацией.
   - Одобрение заявки в 1 клик с моментальным зачислением баллов и пуш-уведомлением студенту в Telegram.
   - Отклонение заявки с возможностью указания причины (причина отправляется студенту).
   - Ручная корректировка баллов прямо перед подтверждением («Изменить баллы»).
2. **➕ Добавить мероприятие**:
   - Пошаговый FSM-мастер: Название ➔ Дата (поддерживает `сегодня` или формат `ДД.ММ.ГГГГ`) ➔ Тип (Учебное / Внеучебное).
   - Новое событие сразу становится доступно для подачи заявок.
3. **⚖️ Ручные баллы**:
   - Поиск студента по Telegram ID, части фамилии или учебной группе.
   - Ввод произвольного количества баллов (`+25`, `-10`).
   - Обязательное указание причины (сохраняется в историю `PointHistory` и отображается студенту).
4. **📈 Рейтинг и статистика**:
   - Количество зарегистрированных студентов.
   - Статистика по мероприятиям и заявкам (в ожидании / одобрено / отклонено).
   - Суммарное количество начисленных баллов и топ-5 лидеров.
